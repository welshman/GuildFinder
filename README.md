# Guild Finder (WoW Forever)

A two-sided recruitment board for WoW Forever: guilds advertise and recruit, players advertise as looking for a guild.
Contact is by whisper (pre-filled; you always press Enter yourself). Adverts are shared with other Guild Finder
users through a private channel.

Your faction and ruleset are detected automatically; you only see listings that match both.

## Install
1. Close WoW.
2. Put the `GuildFinder` folder in `World of Warcraft\_forever_\Interface\AddOns\`
   so that `AddOns\GuildFinder\GuildFinder.toc` exists.
3. Start the game, click AddOns at character select and enable "Guild Finder".

## Commands
/gfinder, /gfboard or /glf  (/gf and /guildfinder belong to Blizzard)
- (none) toggle window, settings, refresh, renew, status, channel, rejoin, debug [on|off|log], reset
- /gfmap shows or hides the minimap button

## Features
- Find a Guild / Find Members, search and filters (type, role, raid, level stage, class, level, days, times, timezone, ...)
- Guild adverts: raid target (Barrow Deeps 10, Hyjal Summit 20, Onyxia's Lair 40), open tank/healer/DPS spots
- Favourites, contacted history and private notes (local only)
- Chat advert helper: a one-line version of your advert to copy and paste yourself
- Optional: read guild posts from General / Trade chat (off by default, unverified, never shared)
- Expiry reminders, batched match notifications with a minimap pulse
